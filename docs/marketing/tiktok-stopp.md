# TikTok: "STOPP" (influencer style)

Video: *EasyTrans TikTok Stopp* (9:16, 25 s). The film carries word-by-word captions, cuts and a
beat; the **voice is added in CapCut or TikTok** (see below). Problem first, then the reveal.

Written in second person ("du"), not as a made-up personal story, so it is not a fake testimonial.
Mark the post as promotional content in TikTok (*Inhalte offenlegen*), since it advertises your own app.

## Adding the voice

**CapCut (best quality):** import the exported MP4 → *Text* → add each line at its time →
select the text → *Text to speech* → pick a German female voice → turn the music down to about
20–30 % → export. Then delete the text layers again; the captions are already in the video.

**TikTok app:** upload the MP4 → *Text* → add each line at its time → tap the text →
*Text-to-speech* → choose a German voice → *Clip duration* to match the table → lower the
original sound.
